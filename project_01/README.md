## 기획 배경

디지털 문구는 종류가 다양하지만 용도와 차이가 한눈에 보이지 않으면 자신에게 맞는 상품을 고르기 어렵습니다.
상품을 **다이어리 · 플래너 · 저널 · 스티커 · 무료 서식**으로 분류하고, 탐색 과정에서 브랜드의 분위기도 함께 경험하도록 설계했습니다.

- **Main 타겟** 자기계발형 Z세대: 목적에 맞는 디지털 템플릿을 빠르게 찾고 싶은 사용자
- **Sub 타겟** 감각형 직장인: 기능과 함께 디자인 분위기와 시각적 완성도를 중시하는 사용자
- **정보구조** 상품 종류 중심 분류에서 사용자 흐름 중심으로 보완
  브랜드 이해(소하는요) → 상품 탐색(디지털 문구) → 구매 확신(솔직후기 · 무료 서식) → 도움 받기(알립니다 · 궁금해요)
- **메인 화면 흐름** 첫인상(메인 비주얼) → 관심 유도(신상품 · 베스트) → 탐색 확장(무료 서식 · 키워드 추천) → 신뢰 형성(후기 · 사용법 · 상담) → 구매(상세 · 장바구니)

## 주요 기능

- **메인 비주얼**: Swiper.js 슬라이드와 상품 배너
- **상품 탐색**: hover 시 이미지 전환, 카테고리 탭, 키워드 추천상품 탭메뉴, 서브페이지 페이지네이션
- **쇼핑몰 UI**: 장바구니 · 최근 본 상품 hover 패널(닫힘 1초 지연)
- **페이지 이동**: 고정 헤더, jQuery scrollTo TOP 버튼, 상세정보 · 후기 · Q&A 앵커 이동(헤더 높이만큼 offset)

## 경쟁 사이트 분석 → 반영

| 분석 요소 | 발견한 점 | 소하에 반영 |
|---|---|---|
| TOP 버튼 | 긴 페이지 탐색 편의 | jQuery scrollTo로 TOP 버튼 구현 |
| 키워드 추천 | 취향별 상품을 빠르게 탐색 | 키워드 추천상품 탭메뉴 |
| 사용법 안내 | 디지털 문구 초보자의 진입장벽 완화 | 사용법 콘텐츠 영역 배치 |
| 무료 콘텐츠 | 첫 방문 사용자의 관심 유도 | 무료 서식 카테고리 |

## 개선 과정

| 문제 | 개선 | 결과 |
|---|---|---|
| 긴 페이지 이동이 불편하고 상세 탭 제목이 고정 헤더에 가려짐 | TOP 버튼 추가, 앵커 이동에 헤더 높이만큼 offset 적용 | 원하는 정보와 상단으로 빠르게 이동 |
| 폴더 구조 변경 후 상대경로가 남아 상품 · 이미지 링크가 열리지 않음 | 페이지별 `href` · `src` 재점검, 미구현 상품에 안내 메시지 추가 | 메인 → 목록 → 상세 흐름 안정화 |
| 장바구니 · 최근 본 상품 닫힘 방식이 불편 | 클릭 → hover 방식으로 변경, 닫힘 지연 적용 | 탐색 중 빠르게 확인 가능 |
| 색상 · 브레이크포인트 값이 CSS 파일마다 반복됨 | Sass로 리팩터링, `_variables.scss`에 공통 색상 · 반응형 기준점을 변수로 모으고 각 파일에서 `@use` | 값 변경이 한 곳에서 끝남 |
| 이미지 파일명이 번호(`05_best01.jpg`)라 관리가 어려움 | 상품명 기반 파일명(`best_bullet-journal.jpg`)과 상품명 `alt` 적용 | 유지보수성 · 접근성 개선 |

## 회고

기획부터 디자인, 코딩까지 처음부터 혼자 진행하다 보니 부족한 점이 많았습니다. 하지만 직접 부딪혀 보면서 왜 기획 과정을 먼저 거쳐야 하는지 알게 되었습니다. 타겟과 정보 구조를 먼저 정리해 두면 화면 구성과 구현의 기준이 분명해지고, 콘텐츠 우선순위와 사용자 흐름도 함께 점검할 수 있었습니다.

완성 후에는 받은 피드백을 하나씩 반영하며, 웹퍼블리싱이 한 번 만들고 끝나는 작업이 아니라 사용자의 움직임을 예상하며 다듬어 가는 과정이라는 것을 배웠습니다. 이후 Sass로 리팩터링하면서는 색상 · 그리드 같은 기준을 기획 단계에서 먼저 정해 두면 나중에 수정할 일이 훨씬 줄어든다는 것도 깨달았습니다.

**현재 한계**: 데스크톱 중심 제작 · 대표 상세페이지 1종 · 결제/회원정보 등 서버 기능 제외
**후속 개선**: 일부 jQuery UI를 Vanilla JavaScript로 전환하며 학습 중, 반응형 레이아웃 적용 예정

## 폴더 구조

```
project_01/
├─ index.html      메인
├─ sub/            서브 페이지 (브랜드 · 상품 · 상세 · 후기 · FAQ · 공지 · 로그인 등)
├─ scss/           Sass 원본 (_variables.scss: 공통 색상 · 브레이크포인트)
├─ css/            빌드 결과물 (GitHub Pages가 그대로 사용)
├─ js/main.js
└─ img/            메인 · 공통 이미지 (서브 페이지는 각 폴더의 img/)
```

**CSS 빌드**: `project_01` 폴더에서 `npx sass@1.83.0 --no-source-map scss:css` 실행 후 `css/`도 함께 커밋
