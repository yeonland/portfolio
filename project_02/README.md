## 기획 배경

처음에는 제가 근무했던 시공문화재연구원 사이트를 리뉴얼하려고 했습니다. 하지만 BI · 로고 · 설립 목적처럼 기관 사이트에 기본으로 있어야 할 정보가 없어, 리뉴얼의 기준을 세우기 어려웠습니다.

그래서 다른 문화재 조사기관 사이트들을 비교했습니다. 대부분은 최근에 반응형으로 개편한 상태였지만, 한화문물연구원은 **PC 화면만 있어 휴대폰에서 보기 어려웠습니다.** 동시에 기관 소개 · 조사 절차 · 현장 공개 · 유적 갤러리처럼 조사기관에 있을 법한 콘텐츠는 모두 갖추고 있어, 반응형 리뉴얼이 가장 필요하면서도 구조를 다시 짜 볼 만한 사이트라고 판단했습니다.

- **문제** 휴대폰에서 글씨와 메뉴가 작아 읽고 누르기 어려움, 텍스트가 많은 화면
- **방향** 모바일 우선 반응형, 문화재 조사 실무 경험을 바탕으로 조사 절차 · 현장 공개 콘텐츠 구조를 다시 정리

## 디자인 시스템

| 컬러 | 폰트 | 반응형 기준 |
|---|---|---|
| `#475775` `#6987D6` | IBM Plex Sans KR | 모바일 ~600px / 태블릿 601–1024px / PC 1025px~ |

## 주요 기능

- **반응형 레이아웃**: 모바일 우선으로 작성하고 600px · 1024px 기준 3단계로 확장, 배너는 `picture`로 기기별 이미지 교체
- **메뉴**: PC 메뉴와 모바일 전체 메뉴(햄버거)를 분리
  - PC: 상위 메뉴 버튼과 하위 메뉴를 같은 `li` 안에 두어, 하위 메뉴로 마우스를 옮겨도 닫히지 않음. 닫힌 메뉴는 `visibility: hidden`으로 클릭 · Tab 이동 대상에서 제외. Enter/Space로 열고 Tab으로 하위 링크 이동, ↓로 첫 하위 링크 이동, Escape로 닫고 버튼으로 초점 복귀
  - 모바일 · 태블릿: 체크박스/라벨 대신 `button` + `aria-expanded`, 분류는 탭(↑↓ · Home · End). Escape · 닫기 버튼 · (태블릿) 바깥 영역 클릭으로 닫기, 닫으면 메뉴 버튼으로 초점 복귀, 열린 동안 Tab 초점 순환 + 뒤쪽 콘텐츠 `inert`
- **페이지 이동**: 스크롤하면 고정되는 헤더, TOP 버튼, 본문 바로가기. 메인 안에 있는 현장공개 · 유적 갤러리 · 공지사항 · 언론보도 · 관련사이트 메뉴는 해당 섹션 앵커로 연결
- **메인 화면**: 메인 비주얼 페이드 슬라이드(일시정지/재생 버튼, 움직임 줄이기 설정 시 자동 재생 안 함), 바로가기 · 조사 절차 아이콘 hover 이미지 전환, 현장공개 썸네일 버튼(`aria-pressed`), 공지사항 · 언론보도 탭(←→ · Home · End)
- **미구현 기능 표시**: 검색 · 로그인 · 더보기 · 하위 페이지 등은 링크 대신 `aria-disabled` 요소로 바꾸고 회색 · "준비 중" 배지로 표시, 누르면 안내 메시지(`role="status"`) 표시. 푸터와 메뉴에 "메인 · 인사말만 구현한 학습용 사이트" 안내
- **읽기 편한 화면**: 텍스트가 많은 화면에 사진 · 여백 · 줄 간격을 더해 정리
- **접근성**: 옆에 글자가 함께 있는 장식용 아이콘 · 배너 · 갤러리 이미지(캡션은 `figcaption`)는 `alt=""`로 두어 화면 낭독기가 같은 내용을 두 번 읽지 않도록 함. 화면 확대 제한(`maximum-scale`, `user-scalable=no`) 제거, 키보드 초점 표시

## 개선 과정

| 문제 | 개선 |
|---|---|
| 메뉴에 hover하면 화면 전체가 흔들림 | 위치 값만 맞추지 않고, 어떤 요소가 공간을 차지하는지 CSS 구조부터 확인해 수정 |
| `.fixed` 요소 때문에 레이아웃이 어긋남 | 어긋난 위치만 맞추지 않고 CSS 구조부터 확인해 수정 |
| PC 메뉴가 `.gnb_pc:hover ~ .menu_box_pc`에만 의존해 하위 메뉴로 이동하면 닫히고, 닫힌 메뉴가 `opacity: 0`으로만 숨겨져 클릭 · Tab 이동됨 | 상위 · 하위 메뉴를 한 `li`로 묶고 JS로 열림 상태(`aria-expanded`) 관리, 닫힘은 `visibility: hidden` |
| 태블릿(768px) 조사절차 카드가 기본 `flex: 1` 때문에 `width: 49%`가 무시되어 4열로 남음 | Grid로 변경(모바일 · 태블릿 2열, PC 4열), 카드 내부 `float`를 flex로 교체 |
| 1050px에서 각 `530px`인 공지사항 · 언론보도가 한 줄에 들어가지 않음 | `minmax(0, 1fr)` 2열 Grid, 고정 너비 · float · `height: 230px` 제거, 제목(말줄임) · 날짜를 flex로 배치 |
| 모바일 바로가기 글자 약 10px, 배너 글자 10px · 높이 69px로 답답함 | 바로가기 2×2 · 15px, 배너 최소 높이 130px · 14px |
| 모바일 유적 갤러리 제목과 더보기가 붙음 | 제목 줄이 Grid 한 줄 전체(`grid-column: 1 / -1`)를 차지 |
| 모바일 메인 비주얼이 `100vh`라 아래 콘텐츠가 보이지 않음 | 모바일만 `70svh` |
| PC "국가유산청 공간정보서비스"가 한국문화유산협회 주소로 연결됨 | 모바일과 같은 `gis-heritage.go.kr`로 수정 |
| 1050px에서 PC 유적 갤러리 · 인사말 페이지(고정 `1070px`)에 가로 스크롤 발생 | 고정 너비 · 좌우 margin 제거, `min(calc(100% - 32px), 1070px)`로 통일 |

**검증** 390 · 768 · 1050 · 1440px에서 메인 · 인사말을 Playwright(Chromium)로 확인 — 가로 넘침 없음, 공지 제목 · 날짜 겹침 없음, PC 메뉴 hover 이동 · 키보드 열기/닫기, 모바일 메뉴 열기 · 닫기 · Escape · 초점 순환, 탭 · 썸네일 키보드 전환, 슬라이드 일시정지.
