# 한화문물연구원 — 홈페이지 반응형 리뉴얼

PC 화면만 있던 문화재 조사기관 홈페이지를 모바일·태블릿·PC에서 모두 볼 수 있도록 다시 설계하고 구현한 개인 프로젝트입니다.

- **사이트:** https://yeonland.github.io/portfolio/project_02/
- **Figma 시안:** https://www.figma.com/design/JXINnGgCmQUH3HEMsO4Vyw/

## 왜 이 사이트를 골랐나

처음에는 제가 근무했던 시공문화재연구원 사이트를 리뉴얼하려고 했습니다. 하지만 BI·로고·설립 목적처럼 기관 사이트에 기본으로 있어야 할 정보가 없어, 리뉴얼의 기준을 세우기 어려웠습니다.

그래서 다른 문화재 조사기관 사이트들을 비교했습니다. 대부분은 최근에 반응형으로 개편한 상태였지만, 한화문물연구원은 **PC 화면만 있어 휴대폰에서 보기 어려웠습니다.** 동시에 기관 소개·조사 절차·현장 공개·유적 갤러리처럼 조사기관에 있을 법한 콘텐츠는 모두 갖추고 있어, 반응형 리뉴얼이 가장 필요하면서도 구조를 다시 짜볼 만한 사이트라고 판단했습니다.

## 한 일

- Figma로 화면을 설계한 뒤 HTML·CSS·jQuery로 구현
- 모바일 우선 반응형: 600px / 1024px 기준 3단계, 배너는 `picture`로 기기별 이미지 교체
- PC 메뉴와 모바일 전체 메뉴를 분리
- 스크롤하면 고정되는 헤더와 TOP 버튼
- 메인 비주얼 페이드 슬라이드, 바로가기 아이콘 hover 이미지 전환
- 문화재 조사 실무 경험을 바탕으로 조사 절차·현장 공개 콘텐츠 구조 정리
- 텍스트가 많은 화면에 사진·여백·줄 간격을 더해 읽기 편하게 정리
- 옆에 글자가 함께 있는 장식용 아이콘·배너 이미지는 `alt=""`로 두어 화면 낭독기가 같은 내용을 두 번 읽지 않도록 함
