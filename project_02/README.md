## 기획 배경

문화재 조사기관에서 근무한 경험을 바탕으로, 기관의 정보를 이용 목적에 맞게 정리하는 반응형 사이트를 만들고자 했습니다.

처음에는 제가 근무했던 시공문화재연구원 사이트를 대상으로 검토했지만, 당시 사이트에서 확인할 수 있는 BI·로고·설립 목적 등의 정보가 부족해 리뉴얼의 기준을 잡기 어려웠습니다.

이후 다른 문화재 조사기관 사이트를 비교하면서 한화문물연구원을 선정했습니다. 프로젝트 진행 당시 기관 소개와 조사·연구 자료는 갖추고 있었지만 PC 중심의 화면으로 구성되어 있어, 모바일에서 읽고 이용하기 편하도록 재구성할 필요가 있다고 판단했습니다.

## 기획 의도

조사기관 사이트에서는 기관의 성격을 전달하는 것과 함께, 방문자가 필요한 정보로 이동할 수 있는 경로가 중요하다고 생각했습니다.

실무 경험과 기존 사이트 분석을 바탕으로 주요 이용 목적을 **문화재 조사 의뢰와 연구자료 탐색**으로 설정했습니다. 조사절차와 주요 서비스의 우선순위를 높이고, PC·태블릿·모바일에서 콘텐츠를 확인할 수 있도록 화면을 설계했습니다.

| 주요 사용자 | 예상 이용 목적 | 설계 방향 |
|---|---|---|
| 문화재 조사 의뢰자 | 조사 종류와 절차, 비용·문의 경로 확인 | 조사절차와 조사의뢰·경비계산 바로가기 배치 |
| 학생·연구자 등 자료 탐색자 | 조사보고서와 연구자료 확인 | 발간보고서·자료요청 진입 경로를 메인에 배치 |
| 내부 연구원 | 내부 업무 서비스 이용 | 외부 방문자를 위한 콘텐츠와 업무 링크 구분 |

※ 사용자 구분은 인터뷰나 이용 통계가 아닌, 실무 경험과 사이트 분석을 바탕으로 설정했습니다.

## 분석에서 설계로

### 1. 주요 이용 목적에 맞춰 메뉴 재구성

기존 사이트에서는 문화재 조사의뢰가 커뮤니티 하위에 배치되어 있었습니다. 조사 의뢰를 주요 이용 목적 중 하나로 보고, 리뉴얼에서는 ‘조사의뢰’를 상위 메뉴로 분리했습니다.

발간보고서와 자료요청은 메인 바로가기에도 배치해, 전체 메뉴를 열지 않고도 해당 기능의 위치를 파악할 수 있도록 구성했습니다.

### 2. 조사절차를 메인 콘텐츠로 배치

조사를 의뢰하려는 방문자가 조사 종류를 먼저 확인할 수 있도록, 메인 비주얼 다음에 ‘문화재 조사절차’ 영역을 배치했습니다.

지표조사·참관조사·표본·시굴조사·발굴조사를 아이콘과 명칭으로 구분하고, 태블릿과 PC에서는 간단한 설명도 함께 제공하도록 구성했습니다.

### 3. 유사기관의 바로가기 구성 참고

대한문화재연구원의 보고서·자료요청·조사문의 바로가기와 혜안문화재연구원의 연구자료실·조사 안내 구성을 참고했습니다. 해동문화재연구원에서는 유물 이미지를 활용한 화면과 모바일 메뉴 사례를 살펴봤습니다.

이를 바탕으로 한화문물연구원의 주요 기능을 **발간보고서·자료요청·조사의뢰·조사경비계산**으로 묶고, 아이콘과 텍스트를 함께 사용해 구분했습니다.

### 4. 연구 활동을 이해할 수 있도록 콘텐츠 구분

기존 유적 이미지 영역은 개별 사진 제목은 있었지만, 콘텐츠 묶음의 성격을 설명하는 제목이 부족했습니다.

리뉴얼에서는 ‘현장공개’와 ‘유적 갤러리’를 별도 섹션으로 구분했습니다. 현장공개에는 썸네일을 선택해 큰 이미지를 바꾸는 기능을 구현하고, 유적 갤러리에는 사진별 설명을 함께 배치했습니다.

### 5. 기기별로 메뉴와 콘텐츠 배치 변경

PC에서는 상단 메뉴와 하위 메뉴를, 모바일·태블릿에서는 전체 메뉴를 열어 항목을 선택하는 방식을 적용했습니다.

화면 너비에 따라 배너 이미지를 교체하고, 주요 바로가기와 이미지 영역의 배치를 변경했습니다. 공지사항과 언론보도는 PC에서는 나란히 보여주고, 작은 화면에서는 탭으로 전환하도록 구성했습니다.

## 구현 범위

메인 페이지와 인사말 서브 페이지를 디자인하고 퍼블리싱했습니다.

- 메인: 조사절차, 주요 서비스 바로가기, 현장공개, 공지·언론보도, 유적 갤러리
- 인사말: 연구원 소개와 연구 방향
- 인터랙션: 모바일 메뉴, 메인 이미지 자동 전환, 현장공개 이미지 선택, 공지·언론보도 탭, 고정 헤더, TOP 버튼

보고서 검색·자료요청·조사의뢰·경비계산은 메뉴와 진입 화면 구성에 포함했으며, 상세 페이지와 실제 처리 기능은 구현 범위에 포함하지 않았습니다.

## 디자인 시스템

| 컬러 | 폰트 | 반응형 기준 |
|---|---|---|
| `#475775` `#6987D6` | IBM Plex Sans KR | 모바일 ~600px / 태블릿 601–1024px / PC 1025px~ |

## 주요 기능

- **반응형 레이아웃**: 모바일 우선으로 작성하고 600px · 1024px 기준 3단계로 확장, 배너는 `picture`로 기기별 이미지 교체
- **메뉴**: PC 메뉴와 모바일 전체 메뉴(햄버거)를 분리
- **페이지 이동**: 스크롤하면 고정되는 헤더, TOP 버튼
- **메인 화면**: 메인 비주얼 페이드 슬라이드, 바로가기 · 조사 절차 아이콘 hover 이미지 전환
- **읽기 편한 화면**: 텍스트가 많은 화면에 사진 · 여백 · 줄 간격을 더해 정리
- **접근성**: 옆에 글자가 함께 있는 장식용 아이콘 · 배너 이미지는 `alt=""`로 두어 화면 낭독기가 같은 내용을 두 번 읽지 않도록 함

## 개선 과정

| 문제 | 개선 |
|---|---|
| 메뉴에 hover하면 화면 전체가 흔들림 | 위치 값만 맞추지 않고, 어떤 요소가 공간을 차지하는지 CSS 구조부터 확인해 수정 |
| `.fixed` 요소 때문에 레이아웃이 어긋남 | 어긋난 위치만 맞추지 않고 CSS 구조부터 확인해 수정 |
